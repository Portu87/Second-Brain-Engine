# Security policy

## Supported versions

Only the latest released minor version receives security fixes during the alpha phase.

## Reporting

Do not open a public issue for a vulnerability that could expose data or credentials. Report it
privately through GitHub's security advisory feature for this repository.

## Data handling

Never commit passwords, API keys, private keys, payment data, identity documents, health records or
other unnecessary sensitive material. Classification metadata does not encrypt content. Raw sources
inherit the repository's access boundary.

## Disclosure

Please allow maintainers reasonable time to validate and remediate a report before public disclosure.
