# Roadmap

## 0.1 — foundation

- project initialization;
- immutable local source ingestion;
- JSON schemas;
- approved decision events;
- deterministic canonical compiler;
- structural, authority, traceability, graph and security validation;
- CLI, tests and CI.

## 0.2 — hardened lifecycle

- signed source manifests and approved-decision hashes;
- explicit migrations and rollback bundles;
- generated pending dashboards and project indexes;
- policy configuration without code changes;
- richer privacy and retention policies;
- pluggable storage backends.

## 0.3 — candidate knowledge

- schemas for observations, claims, entities and hypotheses;
- extraction pipelines that can only propose, never approve;
- contradiction queues and human review workflows;
- semantic audit adapters with evidence-linked findings.

## 1.0 — stable engine

- versioned schema migrations;
- end-to-end reproducibility guarantees;
- signed releases and supply-chain provenance;
- documented compatibility policy;
- reference deployment and backup/restore drills.
